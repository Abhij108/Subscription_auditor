# 💳 Subscription Auditor

> A smart bank statement analyzer that detects recurring payments, identifies potential subscriptions, and estimates monthly and annual spending.

Subscription Auditor is a full-stack web application designed to help users understand where their money goes.

Users can upload a bank statement in CSV format, and the application analyzes the transactions to identify recurring payments and subscription-like expenses.

---

## 🚀 Features

- 📂 Upload bank statements in CSV format
- 🔍 Automatically analyze transactions
- 🔄 Detect recurring payments
- 💳 Identify potential subscriptions
- 📊 Calculate monthly subscription spending
- 💰 Calculate estimated annual subscription cost
- 📈 Visualize annual spending
- 📊 Visualize subscription frequency
- 🧾 Display detected subscriptions
- 💸 Display recent transactions
- 🎯 Calculate subscription confidence score
- 🏷️ Categorize recurring payments
- 📱 Responsive dashboard
- 🎨 Modern black, white and colorful dashboard UI
